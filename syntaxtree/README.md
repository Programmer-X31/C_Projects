# Syntax Tree Generator
## What it does
This program takes in a C program and generates a tree view of the variables and function names in their scopes, each scope represented using indentation.

## How does a C program work
- Variables are defined after the keywords `int`, `char`, `double`, `float`
- Functions are also defined after the keywords `int`,`char`, `double`, `float` followed by parenthesis
- Loops are started using keywords `for`, `while` followed by a set of parenthesis, then followed by a set of curly brackets
